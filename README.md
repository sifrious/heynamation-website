# Heynamation, LLC website

Static company information page for heynamation.com, hosted on GitHub Pages.

## Files

- `index.html` contains the company details and website privacy notice.
- `styles.css` defines the responsive layout and keyboard focus styles.
- `CNAME` preserves the custom domain, `heynamation.com`.
- `.nojekyll` lets GitHub Pages serve the files without Jekyll processing.

The complete page works without JavaScript. It uses system fonts and has no forms, analytics, cookies, browser storage, or external assets. GitHub's hosting may collect request data as described in the linked GitHub privacy statement.

## Preview and publication

Run `python3 -m http.server 8080` from the repository root and open `http://localhost:8080`. GitHub Pages publishes the configured source branch. Preserve the existing Pages source and domain settings when merging changes.

## Content scope

The page identifies Heynamation, LLC and describes this website's actual behavior. It does not assert that the company meets a particular legal requirement or verification program. No business address, registration jurisdiction, registration number, or contact email was supplied, so none is invented here. Add verified details to `index.html` if a particular reviewer or jurisdiction requires them.

Update the privacy notice whenever data collection, hosting, or third-party integrations change. The notice covers this website only, not the company's other products or services.
