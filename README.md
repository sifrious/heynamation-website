# Heynamation, LLC website

A Laravel 13 application serving the company information page as complete HTML. The application lives at the repository root so Laravel hosting services can detect `composer.json` and `artisan`.

## Local development

Requires PHP 8.3 or newer and Composer. Development dependencies require PHP 8.3 or newer as well.

```sh
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Open `http://localhost:8000`. No Node.js build, database, migrations, queue worker, or Statamic installation is needed.

## Deployment

Select this repository and branch `main`. Use the repository root as the application directory and `public` as the web document root.

Build command:

```sh
composer install --no-dev --prefer-dist --optimize-autoloader --no-interaction
```

Deploy command, after production environment variables are available:

```sh
php artisan optimize
```

Set `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL` to the actual HTTPS site URL, and a persistent `APP_KEY` generated by the hosting platform or `php artisan key:generate --show`. Store the key in the hosting platform's secret settings, never in Git. Use PHP 8.4 for deployment. Health checks use `/up`. Laravel needs write access to `storage` and `bootstrap/cache`.

This repository no longer targets GitHub Pages. The existing domain remains associated with the old site until its owner changes hosting and DNS. Configure the custom domain and HTTPS on the new host before retiring the old repository.

## Implementation

- `routes/web.php` defines the read-only homepage route.
- `resources/views/company.blade.php` contains the page and privacy notice.
- `public/styles.css` contains the responsive styling.
- `bootstrap/app.php` registers routing and the health check.
- `tests/Feature/WebsiteTest.php` verifies rendering, no response cookies, health checks, missing pages, and rejected POST requests.
- `docs/configuration.md` describes deployment configuration.
- `docs/glossary.md` defines the page's terminology.

The homepage excludes the web middleware group because it has no sessions, forms, or authentication. Other future web routes retain Laravel's standard middleware. Restore the normal middleware for any new forms or authentication. The page uses system fonts and no JavaScript, analytics, browser storage, or external assets.
